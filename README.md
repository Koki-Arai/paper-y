# Paper Y Replication: 法的理由付けモデルの構造推定と検証可能性ランドスケープ

論文 Y「法的理由付けモデルの構造推定と検証可能性ランドスケープ」(荒井弘毅、2026)の実証分析を再現するためのコードと資料を提供するリポジトリです。

本リポジトリは、判決テキスト 6,724 件(2015〜2024 年)に基づく以下の実証分析を実装します。

- **構造推定(SMM)**:領域別パラメータ $\hat{\theta}_c = (\hat{\beta}_c, \hat{\kappa}_c, \hat{\eta}_J^c, \hat{M}_{AV}^c, \hat{M}_H^c, \hat{M}_{LS}^c, \hat{K}_c^c)$ の同定
- **検証テスト群**:命題 2(条件付き命題)に対する 9 テスト + 命題 3(三軸統合命題)に対する 10 テスト、計 19 個の独立検証テスト
- **差分の差分推定**:改正民法債権法(2020 年 4 月施行)前後を利用した T-DiD-4
- **反実仮想シミュレーション**:制度設計含意の定量化
- **主成分分析**:認知メタ軸 $\pi^M$ の二次元化(PC1 38.4%、PC2 19.7%)

## 対応する理論論文

本実証編は、別稿の理論論文(論文 X、荒井 2026)で展開される動学的ベイズ・シグナリング・ゲームのモデルに対する判決テキスト・データに基づく検証を提供します。論文 X は、田中亘編『法学の方法』(2026)所収の 9 論文への経済分析的応答として、四条件(西内・飯田・矢作・藤谷)の内側化と三軸(石川・林・稲谷)の境界領域への展開を組み込む三命題(命題 1〜3)の階層を提示しています。

## データ

本リポジトリで使用するデータは、裁判所サイトから公開されている判決文を整理して構築した 6,724 件のサンプル(2015〜2024 年)です。各レコードは、語彙頻度ベースで構築された以下の主要変数を含みます。

| 変数 | 内容 |
|---|---|
| `case_id` | 事件番号(裁判所ウェブサイト準拠) |
| `decision_date` | 判決日 |
| `domain` | 領域(民事・商事・行政・刑事) |
| `mu_F` | フィクション成分 $\mu^F$ |
| `mu_T` | 翻訳成分 $\mu^T$ |
| `nu` | 規範構造の有無 $\nu$ |
| `pi_V` | 実体的価値判断明示度 $\pi^V$ |
| `pi_C` | 権限配分判断明示度 $\pi^C$ |
| `pi_H` | 歴史的判断明示度 $\pi^H$ |
| `pi_M_S` | 司法的役割成分 $\pi^{M, S}$ |
| `pi_M_R` | 論証様式成分 $\pi^{M, R}$ |
| `mu_LS` | 法社会学媒介 $S_A \cdot M_{LS}$ |
| `mu_TH` | 歴史的翻訳成分 $\mu^{T, H}$ |

データセット `hanrei_features_v3_3_2015_2024.csv` は、利用者各自で `data/` ディレクトリに配置する必要があります。リポジトリにはサンプルデータ(50 行)のみを `data/sample.csv` として提供します。

## 使用方法

### 環境構築

```bash
# Python 3.9 以上を推奨
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### データの配置

```bash
# data/hanrei_features_v3_3_2015_2024.csv を配置
cp /path/to/your/data.csv data/
```

### 全体実行

```bash
# 全分析を順次実行(SMM → P2 テスト → P3 テスト → DiD → PCA → 反実仮想)
python src/run_all.py
```

### 個別実行

```bash
# データ前処理のみ
python src/01_data_loader.py

# SMM 構造推定
python src/02_smm_estimation.py

# 命題 2 関連テスト群
python src/03_tests_p2.py

# 命題 3 関連テスト群
python src/04_tests_p3.py

# 改正民法 DiD
python src/05_did_analysis.py

# PCA 認知メタ軸分析
python src/06_pca_analysis.py

# 反実仮想シミュレーション
python src/07_counterfactual.py
```

### 検証テスト総合判定

| 対応する命題 | テスト数 | VERIFIED | PARTIAL | REJECTED |
|---|---|---|---|---|
| 命題 2(四条件 + 林条件) | 9 | 5 | 4 | 0 |
| 命題 3(三軸統合) | 10 | 5 | 4 | 0 |
| 命題 1(修正)| 1 | 0 | 0 | 1 |
| **合計** | **20** | **10** | **8** | **1** |

### 改正民法 DiD(T-DiD-4)

| 結果変数 | $\hat{\delta}$ | SE | $p$ 値 | 判定 |
|---|---|---|---|---|
| $\mu^T$ | $-0.219$ | $0.097$ | $0.023$ | REJECTED |
| $\pi^V$ | $-0.505$ | $0.112$ | $<0.001$ | REJECTED |
| $\pi^C$ | $-0.117$ | $0.086$ | $0.173$ | 非有意 |
| $\mu^F$ | $+0.001$ | $0.013$ | $0.939$ | 非有意 |
| $\pi^M$ | $-0.023$ | $0.013$ | $0.073$ | 弱有意逆方向 |

### PCA 認知メタ軸の二次元化

- **第一主成分(PC1)**:寄与率 38.4%、司法的役割関連語(本判決の趣旨、判決の論理、本件の判断、本件の特殊性)に高負荷
- **第二主成分(PC2)**:寄与率 19.7%、論証様式関連語(総合的判断、個別具体的、考慮要素、おのずから)に高負荷
