# データセット説明

## hanrei_features_v3_3_2015_2024.csv

判決テキストから抽出した特徴量データセット。日本の裁判所サイトから公開されている判決文を整理し、語彙頻度・構造特徴に基づいて構築した特徴量行列です。

### 基本情報

| 項目 | 値 |
|---|---|
| サンプルサイズ | 6,724 件 |
| 期間 | 2015 年 1 月 〜 2024 年 12 月 |
| 領域 | 民事(3,506)、商事(2,093)、行政(639)、刑事(486)|
| ファイル形式 | CSV(UTF-8、ヘッダー行あり)|

|---|---|---|
| `case_id` | string | 事件番号(裁判所ウェブサイト準拠) |
| `decision_date` | date | 判決日(YYYY-MM-DD) |

### データセットの入手方法

本リポジトリには、データセット本体は含まれていません。サンプル(50 行のみ)は `data/sample.csv` として提供しています。完全なデータセットを使用する場合は、以下のいずれかの方法でご入手ください。

1. 著者へお問い合わせください(共立女子大学ビジネス学部、荒井 弘毅)
2. 裁判所ウェブサイト(https://www.courts.go.jp/ ) から判決文を独自にダウンロードし、本リポジトリの前処理スクリプト(別途提供予定の `prepare_features.py`)で特徴量を抽出する

### データの構築方法

1. **判決文収集**:裁判所ウェブサイトから 2015〜2024 年の判例検索システム検索結果に基づき、PDF または HTML 形式で判決文を取得
2. **OCR / テキスト抽出**:必要に応じて OCR を適用し、判決文のテキスト本体を抽出
3. **メタデータ整備**:事件番号、判決日、裁判所、領域分類を判決文ヘッダーから抽出
4. **語彙特徴量抽出**:
   - 田中(2026)のフィクション類型に対応する語彙群から $\mu^F$ を構築
   - 西内(2026)の翻訳概念群から $\mu^T$ を構築
   - 規範形式(条文引用、判例引用、規範文言)の有無から $\nu$ を判定
   - 政策判断明示語彙の各カテゴリから $\pi^V, \pi^C, \pi^H, \pi^M$ を構築
5. **正規化**:各変数を [0, 1] の範囲に正規化

### サンプルデータ(data/sample.csv)

リポジトリには、利用者がコードの動作確認を行うためのサンプルデータ(50 行)を `data/sample.csv` として収録しています。サンプルは民事 25 件・商事 15 件・行政 5 件・刑事 5 件の合計 50 件で、変数は完全版と同じ構成です。

### 利用上の注意

- 判決文の著作権:判決文そのものは公的な文書ですが、本データセットの特徴量行列はオリジナル著作物として扱われ、本リポジトリの LICENSE に従って利用されます
- データ品質:語彙頻度ベースの自動抽出に伴う計測誤差が存在します。特に、$\mu^F$ と $\mu^T$ の区別、および $\pi^{M, S}$ と $\pi^{M, R}$ の区別には、語彙選択の判断が含まれます
- 領域不均衡:刑事領域(486 件)が他領域に比較して少なく、検出力が限定的な場合があります
